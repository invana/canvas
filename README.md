# @aspect-ui/canvas

High-performance WebGPU-first canvas rendering engine and visualization toolkit.

## Packages

| Package | Description |
|---------|-------------|
| [@aspect-ui/canvas-core](./packages/canvas-core) | Core rendering engine with WebGPU/WebGL support |
| [@aspect-ui/canvas-utils](./packages/canvas-utils) | Shared utilities (math, color, etc.) |

## Quick Start

```bash
pnpm install
pnpm build
pnpm storybook
```

## Features

- WebGPU-first with WebGL2 fallback
- Theming system with light/dark modes
- Plugin architecture for extensibility
- Multiple node shapes and edge types
- Rich interactions - pan, zoom, drag, select
- Built-in animations
