**Summary:** `sym:BoardPagesViewPanel` was ported into the design kit as `sym:Workbook`
(`@invana/ui`, design-kit `packages/ui/src/components/ui-extended/workbook.tsx`).
`@invana/ui` is the source of truth for UI chrome, so canvas-ui deletes its copy and every
in-repo user imports `Workbook` from the kit. The same audit found 5 more kit duplicates
(F10–F14). Each has its own row.

| | |
|---|---|
| **What changes** | canvas-ui loses `view-panels/board-pages/` and **10** exports (5 `Board*` + 5 deprecated `Canvas*` aliases). Consumers use `Workbook` from `@invana/ui` |
| **Blocker** | `@invana/ui@0.0.32` **is not published**. npm's latest is 0.0.31, which has no `Workbook`. It exists only on design-kit branch `feat/board-pages` (D-1) |
| **Hidden cost** | The `Workbook` strip uses the `h-control-md` token, which is only in **unreleased** `@invana/styling`. Canvas would jump 0.0.24 → 0.0.32 across the whole kit (104 kit commits, 7 marked breaking), including a type-ladder rename that shrinks every canvas `text-sm` / `text-xs` by 1px unless migrated (F2, F3) |
| **Duplicate audit** | 0 exact · 1 drop-in after a 1-line kit fix (`MenuItemList`) · 1 drop-in (`ClampedText`) · 3 partial swaps · 5 kept (§2.2) |
| **Open decisions** | D-1 … D-6 |

Row status: proposed 1 · accepted 1 · implemented 10 · landed 0 · deferred 4 · rejected 0 · superseded 0

## 2. Design
