# Interface: BubbleSetStyle

Per-set visual style. Resolved against [BUBBLE\_SET\_STYLE\_DEFAULTS](../variables/BUBBLE_SET_STYLE_DEFAULTS.md).

## Properties

### fill?

> `optional` **fill?**: `number`

Solid fill colour `0xRRGGBB`. Default `0x9c88ff`.

***

### fillOpacity?

> `optional` **fillOpacity?**: `number`

Fill alpha 0..1. Default `0.25`.

***

### stroke?

> `optional` **stroke?**: `number`

Stroke colour `0xRRGGBB`. Default same as [fill](#fill).

***

### strokeOpacity?

> `optional` **strokeOpacity?**: `number`

Stroke alpha 0..1. Default `0.9`.

***

### strokeWidth?

> `optional` **strokeWidth?**: `number`

Stroke width in world units. Default `1.5`.
