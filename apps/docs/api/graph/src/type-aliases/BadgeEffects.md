# Type Alias: BadgeEffects

> **BadgeEffects** = [`NodeEffects`](../interfaces/NodeEffects.md)

Host-modulation effects on a badge. Re-exports the [NodeEffects](../interfaces/NodeEffects.md)
surface because a badge is rendered as a shape under the hood — the same
`shake` / `breathing` / future shape-effect kinds apply field-for-field.
