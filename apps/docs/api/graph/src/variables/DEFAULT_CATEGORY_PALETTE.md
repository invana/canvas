# Variable: DEFAULT\_CATEGORY\_PALETTE

> `const` **DEFAULT\_CATEGORY\_PALETTE**: readonly `number`[]

Default 12-colour categorical palette (0xRRGGBB) — distinct hues that read on
both light and dark backgrounds. Cycled when a graph has more values than
colours. Override via [ColorByBehaviourOptions.palette](../interfaces/ColorByBehaviourOptions.md#palette).
