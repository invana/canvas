# Type Alias: TabAlign

> **TabAlign** = `"left"` \| `"center"` \| `"right"`

Where a [TabbedRectSpec](../interfaces/TabbedRectSpec.md)'s tab sits along the body's top edge.
`'left'` / `'right'` measure [TabbedRectSpec.tabOffset](../interfaces/TabbedRectSpec.md#taboffset) in from that
side; `'center'` ignores the offset and splits the remainder evenly.
