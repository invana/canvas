# Variable: textLODFields

> `const` **textLODFields**: `FieldConfig`[]

Schema for the **text** LOD editor — the shared band plus `alwaysShowTop`,
the top-centrality label exemption (text-only). Pass this as `fields` to
[ContentLODEditorPanel](../../../canvas/src/variables/SpecStore.md) when editing a `TextLODBehaviour`.
