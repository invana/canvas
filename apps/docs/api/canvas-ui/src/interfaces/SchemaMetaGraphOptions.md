# Interface: SchemaMetaGraphOptions

Options for [schemaToMetaGraph](../functions/schemaToMetaGraph.md).

## Properties

### edgeRouting?

> `optional` **edgeRouting?**: [`SchemaEdgeRouting`](../type-aliases/SchemaEdgeRouting.md)

Connector routing for the edges. Default `'straight'`.

***

### nodeMode?

> `optional` **nodeMode?**: [`SchemaNodeMode`](../type-aliases/SchemaNodeMode.md)

Render each node-type as a simple disc or a composite ER table. Default `'simple'`.
