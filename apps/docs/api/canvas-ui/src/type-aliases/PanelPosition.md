# Type Alias: PanelPosition

> **PanelPosition** = `"top-left"` \| `"top-center"` \| `"top-right"` \| `"bottom-left"` \| `"bottom-center"` \| `"bottom-right"` \| `"left"` \| `"right"`

Anchor position for a [Panel](../../../canvas/src/variables/SpecStore.md) within its positioned ancestor. The
corner / edge-centre values pin a content-sized overlay; `'left'` / `'right'`
make a **full-height side dock** flush to that edge.
