# Function: hoverActivateOptionsToForm()

> **hoverActivateOptionsToForm**(`o?`): [`HoverActivateFields`](../interfaces/HoverActivateFields.md)

Map a `HoverActivateBehaviourOptions`-shaped patch to the flat
[HoverActivateFields](../interfaces/HoverActivateFields.md) the `@invana/forms` generator renders. There are
no colours, nested groups, or unions — the mapping is a straight passthrough.

## Parameters

### o?

[`HoverActivateOptions`](../interfaces/HoverActivateOptions.md) = `{}`

## Returns

[`HoverActivateFields`](../interfaces/HoverActivateFields.md)
