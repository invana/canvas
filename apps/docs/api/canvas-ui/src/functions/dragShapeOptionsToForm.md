# Function: dragShapeOptionsToForm()

> **dragShapeOptionsToForm**(`o?`): [`DragShapeFields`](../interfaces/DragShapeFields.md)

Map a `DragShapeBehaviourOptions`-shaped patch to the flat
[DragShapeFields](../interfaces/DragShapeFields.md) the `@invana/forms` generator renders. A 1:1 copy —
the `renderer` / `filter` options are not editable here.
