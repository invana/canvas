# Function: nodeStyleFields()

> **nodeStyleFields**(`values?`): `FieldConfig`[]

The full NodeStyle field set as one grouped `FieldConfig[]` — basics followed
by the advanced groups. Retained as the `fields`-override / back-compat
export; the default editor render is the two-tier basics + collapsed-advanced
layout (see [basicNodeStyleFields](basicNodeStyleFields.md) / [advancedNodeStyleFields](advancedNodeStyleFields.md)).

## Parameters

### values?

[`NodeStyleFields`](../type-aliases/NodeStyleFields.md) = `{}`

## Returns

`FieldConfig`[]
