# Function: colorToForm()

> **colorToForm**(`color?`): [`NodeStyleOverviewFields`](../interfaces/NodeStyleOverviewFields.md)

Seed the form from an engine colour (`0xRRGGBB` → `#rrggbb`). Non-numeric
(unset) colours seed an empty field.

## Parameters

### color?

`number`

## Returns

[`NodeStyleOverviewFields`](../interfaces/NodeStyleOverviewFields.md)
